# 人类最强编导

把你正在做的账号、手里的素材和这次想完成的结果告诉它。它会先判断问题到底出在定位、IP、选题、开头、脚本还是复盘，再把需要的环节做到能直接使用。

它适合内容创作者、新媒体运营、个人 IP、创始人和小团队，也会按照不出镜、低预算、一个人制作等真实条件调整方案。

## 什么时候用它

- 只有一个模糊方向，不知道账号应该做给谁看。
- 能力和经历不少，但说不清个人 IP 应该突出什么。
- 手里有很多选题，需要判断第一条先做哪个。
- 标题、封面或开头不够好，但不想靠夸张承诺吸引点击。
- 已有选题，想把它写成能念、能拍、能剪的内容。
- 内容已经发布，需要结合正文和后台数据判断下一条改什么。
- 想用真实任务训练选题、画面、节奏或素材能力。

如果只是润色一句话，普通写作工具已经足够。人类最强编导更适合那些需要先做判断，再进入创作的任务。

## 它不会先给你一堆答案

比如你只说“我想做一个地产账号”，服务对象、业务目标、出镜意愿和现有素材都会改变方案。信息不够时，它只问一至三个真正影响结果的问题；信息已经足够时，直接开始，不会为了走流程重复提问。

它会沿用你已经说过的事实和限制。默认给一个当前最值得执行的方案，而不是用几十个选题掩盖判断。需要备选、对比或选题库时，再明确提出即可。

## 你会拿到什么

| 你现在要解决的问题 | 本次交付 |
|---|---|
| 新账号不知道从哪里开始 | 目标用户、关注理由、内容方向和首轮验证方式 |
| 想做个人 IP 或创始人内容 | 人物重点、可信材料和第一条故事的切入点 |
| 不知道先做哪个选题 | 一个首选选题、选择理由和必须准备的素材 |
| 想优化标题和前几秒 | 标题、封面文案、第一句话、第一画面及正文兑现方式 |
| 想把选题做成完整内容 | 逐字稿、时间轴、镜头安排和拍摄清单 |
| 内容表现不好 | 能确认的事实、主要假设、不能下的结论和下一轮改动 |
| 想提高编导能力 | 一个真实练习、重做要求和判断进步的标准 |

## 直接这样用

### 从零做一个账号和首条内容

```text
使用 $human-best-video-director。

我想做一个不出镜的小红书 AIGC 新账号。
用户是普通职场人和新媒体运营，我擅长商业化落地和内容创作，
手里有真实的 AI 工作流，可以录屏和配旁白。

帮我定账号方向，选一条最适合起号的内容，再写成 60 秒脚本。
```

### 已经有选题，直接进入制作

```text
使用 $human-best-video-director。

选题是“售楼处说离地铁 800 米，我在周一晚高峰实际走一遍”。
用户是第一次买房的上班族。我不出镜，有地图和完整步行录像。

请写一版 60 秒旁白、时间轴和拍摄清单。
还没有测出的数字留空，不要替我编。
```

### 根据真实数据复盘

```text
使用 $human-best-video-director。

这条内容的目标是让用户关注账号。
这是标题、封面、正文、发布时间、发布 72 小时数据，
以及账号最近 10 条内容的平均数据：……

请判断目前能确认什么、还不能确认什么，
以及下一条最值得只改哪一处。
```

## 想精确指定某一步

大多数情况下只用总入口即可。已经知道自己要做哪一步时，也可以直接调用专项能力。

| 调用 | 适合处理 |
|---|---|
| `$hbvd-intake` | 判断信息够不够，并补齐关键缺口 |
| `$hbvd-account` | 账号定位、起号和内容支柱 |
| `$hbvd-ip` | 个人 IP、创始人故事和信任建立 |
| `$hbvd-topic` | 选题判断、优先级和证据要求 |
| `$hbvd-hook` | 标题、封面、第一句话和第一画面 |
| `$hbvd-script` | 文案、时间轴、镜头和拍摄清单 |
| `$hbvd-review` | 内容审稿、数据诊断和下一轮验证 |
| `$hbvd-training` | 编导训练、素材整理和能力复盘 |

## 使用边界

- 不虚构身份、经历、数据、案例、评价和效果。
- 标题与开头必须由正文和真实材料兑现。
- 脚本必须符合预算、人手、时长、素材和出镜意愿。
- 单条数据不足以证明原因时，不自动归因于限流或平台规则。
- 不承诺爆款、涨粉、收入、成交或平台推荐。
