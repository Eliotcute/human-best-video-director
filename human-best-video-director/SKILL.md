# 人类最强编导

一套面向内容创作者、新媒体运营、个人 IP、创始人和小团队的中文编导 Skills。

它处理从“账号应该做给谁看”，到“这一条具体怎么拍”，再到“发布后下一条应该改什么”的完整内容过程。它不会在需求还很模糊时先给一堆选题，也不会替用户编造经历、数据和结果。

## 适合谁使用

- 想从零开始做短视频或小红书账号的创作者。
- 需要账号定位、选题、标题、口播稿或拍摄方案的新媒体运营。
- 想从真实经历中建立个人 IP 或创始人内容的人。
- 不出镜、低预算、素材有限或只有一个人的内容团队。
- 已经发布内容，想根据文稿或后台数据判断下一条该改什么的人。
- 想系统训练需求判断、选题、画面、节奏和素材使用能力的编导。

如果只需要润色一句话，普通写作工具已经足够。这个 Skill 更适合需要先判断方向，再把内容真正做出来的任务。

## 可以完成什么

| 你的问题 | 它会给出什么 |
|---|---|
| 想做账号，但方向很模糊 | 一个能执行的账号方向、目标用户、关注理由和首轮验证 |
| 想做个人 IP 或创始人内容 | 一个基于真实经历的人物重点、信任来源和起步故事 |
| 选题很多，不知道先做哪个 | 当前最值得执行的一条，以及所需素材和淘汰理由 |
| 标题吸引人，正文却接不住 | 能由正文兑现的标题、封面、第一句话和第一画面 |
| 有想法，但写不成能拍的内容 | 口播稿、时间轴、镜头安排和拍摄清单 |
| 内容数据不好，不知道原因 | 已知事实、主要假设、不能下的结论和下一轮改动 |
| 想提高编导能力 | 围绕真实任务的练习、前后对照和验收标准 |

## 怎么使用

直接说清你现在知道的事实和这次希望拿到的结果。例如：

```text
使用 $human-best-video-director。

我想做一个不出镜的小红书 AIGC 新账号。
用户是普通职场人和新媒体运营，我擅长商业化落地和内容创作，
手里有真实的 AI 工作流，可以录屏和配旁白。

帮我定账号方向，选一条最适合起号的内容，再写成 60 秒脚本。
```

信息足够时，它会直接完成任务。确实缺少会改变结果的内容时，它最多问三个关键问题；回答后继续原任务，不需要反复说“继续”。

## 一个入口，八个专项能力

这套工具共有九个 Skill：一个总入口负责理解和整合，八个专项 Skill 负责具体工作。用户通常只需要使用总入口；已经明确需求时，也可以直接使用对应的专项 Skill。

| Skill | 负责什么 |
|---|---|
| `$hbvd-intake` | 判断信息是否足够，并补齐最关键的缺口 |
| `$hbvd-account` | 账号定位、起号、关注理由和内容支柱 |
| `$hbvd-ip` | 个人 IP、创始人故事和信任建立 |
| `$hbvd-topic` | 选题判断、优先级和真实证据要求 |
| `$hbvd-hook` | 标题、封面、第一句话和第一画面 |
| `$hbvd-script` | 文案、时间轴、镜头、素材和拍摄清单 |
| `$hbvd-review` | 内容审稿、数据诊断和下一轮验证 |
| `$hbvd-training` | 编导训练、素材整理和能力复盘 |

## 工作原则

- 先理解真正需求，再开始创作。
- 默认给一个最推荐的方案，不用数量掩盖判断。
- 不重复询问已经回答过的信息。
- 不虚构身份、经历、数据、案例、评价和效果。
- 标题、封面和开头必须由正文与真实证据兑现。
- 脚本必须符合预算、人手、时长、素材和出镜意愿。
- 复盘时区分事实与猜测，不把单条数据自动归因于限流。
- 不承诺爆款、涨粉、收入、成交或平台推荐。
