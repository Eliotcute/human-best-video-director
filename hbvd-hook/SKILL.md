# 钩子与内容承诺

钩子是内容价值的提前展示，不是与正文无关的刺激。

## 接收任务

读取总入口传入的 `HBVD_TASK_BRIEF` 及选题结论。不得重新询问任务合同中已确认的用户、选题、证据和形式；只有事实冲突，或缺口会让承诺无法兑现且无法安全假设时，返回 `NEED_CONTEXT: 字段 + 原因`。

若状态为 `PARTIAL`，不得扩大未经确认的收益。完成后把首选钩子、承诺、证据依赖和正文兑现要求追加回任务合同。

## 前置条件

必须具备：确认的选题、目标用户、正文核心判断、可展示证据、内容形式。

- 只有标题、没有正文价值：停止，返回 `$hbvd-topic` 或 `$hbvd-script`。
- 核心承诺没有真实证据：停止，要求补材料或换题。
- 标题承诺与正文结果不一致：先修正文，不生成新钩子。

## 兑现链路

逐项建立：

`用户具体问题 → 标题与封面承诺 → 第一画面证据 → 正文持续推进 → 明确结果 → 后续关注价值`

标题、封面、第一句话和第一画面必须围绕同一件事；任何一项不得扩大正文无法兑现的承诺。

## 钩子选择

根据现有材料选择一种主要机制：

- **证据型**：已有可见结果、现场、数据或对照。
- **明确收益型**：用户看完能完成具体任务。
- **关键冲突型**：两个真实条件无法同时满足。
- **反常识型**：有事实、案例或逻辑支撑的不同判断。
- **过程未知型**：结果尚未发生，过程确实存在不确定性。

没有对应材料时，不使用该机制。不得虚构数据、权威、客户反馈或转折。

## 默认数量

默认输出一个首选钩子。用户明确要求比较时，最多给三个，并说明各自依赖的证据和风险。

```text
第一句话：
第一画面：

```
